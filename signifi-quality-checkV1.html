Supabase Schema

Run these in your Supabase SQL editor, then add your credentials to the top of the script.

-- 1. Deployments (from Odoo CSV) CREATE TABLE deployments ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), task_id text UNIQUE, parent_ticket text, display_name text, client text, kiosk_id text, location text, stage text, activity_type text, tech text, week_no integer, install_date date, uploaded_at timestamptz DEFAULT now() );
-- 2. Quality scores (one per role per deployment) CREATE TABLE quality_scores ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), deployment_id uuid REFERENCES deployments(id) ON DELETE CASCADE, role text CHECK (role IN ('pm','logistics','install')), submitted_by text, accountability text, comments text, submitted_at timestamptz DEFAULT now(), answers jsonb, score numeric(5,2), UNIQUE (deployment_id, role) );

Enable RLS on both tables and add your anon key policy as needed.
